# 6. Hybrid Search

## 1-Liner Definition

**Hybrid Search** combines dense vector search with sparse keyword
search (BM25) to maximize retrieval accuracy by leveraging both semantic
understanding and exact keyword matching.

------------------------------------------------------------------------

## Architectural Deep Dive

Hybrid search executes **two retrieval pipelines in parallel**:

``` text
                 User Query
                     │
          ┌──────────┴──────────┐
          ▼                     ▼
 Dense Vector Search      BM25 Keyword Search
          │                     │
      Top-K Results         Top-K Results
          └──────────┬──────────┘
                     ▼
       Reciprocal Rank Fusion (RRF)
                     ▼
          Final Ranked Results
```

### Why Hybrid Search?

-   **Dense Search**
    -   Excellent for synonyms and semantic meaning.
    -   Weak for IDs, SKUs, and rare error codes.
-   **Sparse Search (BM25)**
    -   Excellent for exact keywords.
    -   Cannot understand semantic intent.

Hybrid search combines both strengths.

------------------------------------------------------------------------

## Reciprocal Rank Fusion (RRF)

Rather than combining incompatible scores, RRF merges rankings.

\[ RRF(d)=`\sum`{=tex}\_{m}`\frac{1}{k+r_m(d)}`{=tex} \]

Where:

-   **m** = retrieval methods
-   **rₘ(d)** = rank of document *d*
-   **k** = smoothing constant (commonly 60)

------------------------------------------------------------------------

## Comparison

  Feature                     Dense   BM25   Hybrid
  --------------------------- ------- ------ ---------
  Semantic understanding      ✅      ❌     ✅
  Exact keyword match         ⚠️      ✅     ✅
  Synonyms                    ✅      ❌     ✅
  Error codes / SKUs          ⚠️      ✅     ✅
  Overall retrieval quality   High    High   Highest

------------------------------------------------------------------------

## Python Example

``` python
def reciprocal_rank_fusion(dense, sparse, k=60):
    scores = {}

    for rank, doc in enumerate(dense, 1):
        scores[doc] = scores.get(doc, 0) + 1/(k+rank)

    for rank, doc in enumerate(sparse, 1):
        scores[doc] = scores.get(doc, 0) + 1/(k+rank)

    return sorted(scores.items(), key=lambda x: x[1], reverse=True)

dense = ["Doc_A", "Doc_C", "Doc_B"]
sparse = ["Doc_B", "Doc_A", "Doc_D"]

print(reciprocal_rank_fusion(dense, sparse))
```
