# 3. Popular Vector Databases

## Pinecone

Managed cloud-native vector database for enterprise-scale semantic
search.

## Weaviate

Open-source vector database storing objects with embeddings and AI
integrations.

## Chroma

Lightweight embedded vector database ideal for local development.

## Qdrant

Rust-based vector database optimized for fast hybrid search.

## Milvus

Distributed vector database designed for billion-scale datasets.

## FAISS

Meta's high-performance similarity search library (not a database).

## LanceDB

Embedded vector database built on the Lance format.

## pgvector

PostgreSQL extension that adds vector search to SQL.

## Supabase Vector

Managed PostgreSQL with pgvector and built-in APIs.

## MongoDB Atlas Vector Search

Vector search integrated into MongoDB document collections.

## Comparison

  Database          Deployment    Best Use
  ----------------- ------------- -------------------
  Pinecone          Managed       Enterprise RAG
  Weaviate          Open Source   AI apps
  Chroma            Embedded      Prototypes
  Qdrant            Open Source   Production search
  Milvus            Distributed   Massive datasets
  FAISS             Library       Offline indexing
  LanceDB           Embedded      Edge apps
  pgvector          PostgreSQL    SQL + vectors
  Supabase Vector   Managed       Full-stack AI
  MongoDB Atlas     Managed       JSON + vectors
