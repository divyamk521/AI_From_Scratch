# 7. Metadata Filtering

## 1-Liner Definition

**Metadata filtering** applies structured constraints (such as
timestamps, user IDs, categories, or environments) alongside vector
search so results are both semantically relevant and satisfy business
rules.

------------------------------------------------------------------------

## Why Metadata Filtering Matters

Pure vector search ignores business constraints. In production systems,
searches often need filters like:

-   Last 24 hours only
-   Specific organization or user
-   Environment = `production`
-   Document category or status

------------------------------------------------------------------------

## Filtering Strategies

### 1. Pre-Filtering

Apply metadata filters before vector search.

**Pros** - High precision

**Cons** - Can break ANN indexes and force slow scans.

------------------------------------------------------------------------

### 2. Post-Filtering

Run vector search first, then filter results.

**Pros** - Fast ANN search

**Cons** - May discard most results, reducing recall.

------------------------------------------------------------------------

### 3. Single-Stage Hybrid Filtering (Recommended)

Evaluate metadata while traversing the vector index.

**Pros** - Fast - Maintains recall - Used by Qdrant, Pinecone and
pgvector

------------------------------------------------------------------------

## Comparison

  Strategy           Recall       Speed Main Drawback
  ---------------- -------- ----------- -------------------------
  Pre-Filtering        High        Slow Graph fragmentation
  Post-Filtering        Low        Fast Poor recall
  Single-Stage         High   Very Fast Requires native support

------------------------------------------------------------------------

## Python Example

``` python
import math

def cosine_similarity(a, b):
    dot = sum(x*y for x, y in zip(a, b))
    ma = math.sqrt(sum(x*x for x in a))
    mb = math.sqrt(sum(y*y for y in b))
    return dot / (ma * mb)

docs = [
    {"id":"1","env":"production","vec":[0.88,0.12,0.91,0.04]},
    {"id":"2","env":"staging","vec":[0.85,0.14,0.89,0.05]},
]

query = [0.86,0.11,0.89,0.05]

matches = [
    d for d in docs
    if d["env"]=="production"
]

for d in matches:
    print(d["id"], cosine_similarity(query, d["vec"]))
```
