# 5. Similarity Search

## 1-Liner Definition

**Similarity Search** is the process of finding the Top-K vectors that
are closest to a query vector based on a distance or similarity metric
such as Cosine Similarity or Euclidean Distance.

------------------------------------------------------------------------

## Short Technical Explanation

Similarity Search is the final retrieval step in a vector search
pipeline. After text is converted into embeddings and stored in a vector
database, the search engine identifies the nearest vectors.

### Exact Nearest Neighbor (KNN)

-   Compares the query against **every vector**.
-   Guarantees **100% recall**.
-   Complexity: **O(N)**.
-   Suitable for small datasets.

### Approximate Nearest Neighbor (ANN)

-   Searches only a small subset of vectors using indexes like **HNSW**
    or **IVF**.
-   Complexity: approximately **O(log N)**.
-   Recall is typically **95--99%**.
-   Ideal for production-scale systems.

------------------------------------------------------------------------

## Real-World Applications

-   Retrieval-Augmented Generation (RAG)
-   Semantic document search
-   Recommendation systems
-   Duplicate detection
-   Similar image retrieval

------------------------------------------------------------------------

## KNN vs ANN

  Strategy   Method                 Complexity    Recall Best For
  ---------- -------------------- ------------ --------- ------------------------
  KNN        Brute-force search           O(N)      100% Small datasets
  ANN        HNSW / IVF             \~O(log N)   95--99% Large-scale production

------------------------------------------------------------------------

## Python Example

``` python
import math

def cosine_similarity(a, b):
    dot = sum(x*y for x, y in zip(a, b))
    ma = math.sqrt(sum(x*x for x in a))
    mb = math.sqrt(sum(y*y for y in b))
    return dot / (ma * mb)

documents = [
    ("chunk_01", [0.86, 0.11, 0.89, 0.04]),
    ("chunk_02", [0.03, 0.94, 0.12, 0.88]),
]

query = [0.84, 0.14, 0.87, 0.05]

results = sorted(
    [(doc_id, cosine_similarity(query, vec)) for doc_id, vec in documents],
    key=lambda x: x[1],
    reverse=True
)

print(results[0])
```
