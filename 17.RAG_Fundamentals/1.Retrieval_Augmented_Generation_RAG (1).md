# 1. Retrieval-Augmented Generation (RAG)

## 1-Liner Definition

**Retrieval-Augmented Generation (RAG)** is an AI architecture that
connects a Large Language Model (LLM) to an external knowledge source,
enabling accurate, up-to-date, and verifiable responses.

------------------------------------------------------------------------

## The Two Core Problems RAG Solves

### 1. Eliminating Hallucinations

LLMs rely on learned probabilities and may generate incorrect
information when knowledge is missing.

RAG retrieves relevant documents from a vector database and injects them
into the prompt so the LLM answers only using verified context.

### 2. Dynamic Knowledge Updates

Instead of retraining an LLM whenever information changes, RAG updates
only the vector database.

Benefits include:

-   Real-time knowledge
-   Lower cost
-   No catastrophic forgetting
-   Source-backed answers

------------------------------------------------------------------------

## Comparison

  Feature             Standalone LLM   Fine-Tuning   RAG
  ------------------- ---------------- ------------- -----------
  Knowledge Updates   Fixed            Periodic      Real-time
  Hallucinations      High             Medium        Low
  Citations           No               No            Yes
  Cost                Low              High          Moderate

------------------------------------------------------------------------

## RAG Pipeline

``` text
User Query
    ↓
Embedding Model
    ↓
Vector Database
    ↓
Relevant Chunks
    ↓
Prompt Builder
    ↓
LLM
    ↓
Grounded Answer
```

------------------------------------------------------------------------

## Python Example

``` python
def retrieve(query):
    kb = {
        "fastapi": "Use pool_size=20 for async connections."
    }
    return kb.get("fastapi", "No data")

query = "How do I prevent database pool timeouts?"
context = retrieve(query)

prompt = f"Context:\n{context}\n\nQuestion:\n{query}"
print(prompt)
```
