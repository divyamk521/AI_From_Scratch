# 3. RAG Architecture: Ingestion Pipeline vs Query Pipeline

## Architecture Overview

A production Retrieval-Augmented Generation (RAG) system consists of two
independent pipelines:

1.  **Ingestion Pipeline (Offline)** -- Prepares and indexes data.
2.  **Query Pipeline (Online)** -- Retrieves relevant context and
    generates answers.

------------------------------------------------------------------------

## Overall Architecture

``` text
INGESTION PIPELINE
Raw Documents
      ↓
Document Parsing
      ↓
Text Chunking
      ↓
Embedding Model
      ↓
Vector Database (HNSW / IVF)

---------------------------------------

QUERY PIPELINE
User Query
      ↓
Embedding Model (same model)
      ↓
Vector Search
      ↓
Retrieve Top-K Chunks
      ↓
Prompt Augmentation
      ↓
LLM
      ↓
Grounded Response
```

------------------------------------------------------------------------

## Ingestion Pipeline

-   Parse and clean documents
-   Chunk text (typically 256--512 tokens with overlap)
-   Generate embeddings
-   Store vectors, metadata and text in a vector database

### Goal

Prepare searchable knowledge before users ask questions.

------------------------------------------------------------------------

## Query Pipeline

-   Convert the user query into an embedding
-   Search the vector database
-   Retrieve relevant chunks
-   Build an augmented prompt
-   Generate a grounded response using the LLM

> **Important:** Use the **same embedding model** for ingestion and
> querying to ensure vectors lie in the same semantic space.

------------------------------------------------------------------------

## Comparison

  Feature     Ingestion Pipeline   Query Pipeline
  ----------- -------------------- ---------------------
  Execution   Offline              Online
  Purpose     Build index          Retrieve answers
  Latency     Minutes/Hours        Milliseconds
  Main Task   Parsing & Indexing   Search & Generation

------------------------------------------------------------------------

## Python Example

``` python
# Offline
text = "FastAPI database pooling configuration"
embedding = embed(text)
vector_db.insert(text, embedding)

# Online
query = "How do I configure pool size?"
query_embedding = embed(query)
context = vector_db.search(query_embedding)

prompt = f"Context: {context}\nQuestion: {query}"
response = llm(prompt)
```
