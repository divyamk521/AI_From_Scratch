# 2. RAG vs Fine-Tuning vs Long-Context Prompting

## Architecture Breakdown

When building production AI systems, engineers choose between:

-   **RAG** -- Retrieves external knowledge dynamically.
-   **Fine-Tuning** -- Changes model behavior by updating neural
    weights.
-   **Long-Context Prompting** -- Places large amounts of information
    directly into the prompt.

------------------------------------------------------------------------

## Comparison

  ---------------------------------------------------------------------------
  Feature           RAG               Fine-Tuning       Long-Context
  ----------------- ----------------- ----------------- ---------------------
  Primary Goal      Knowledge         Behavior          Large document
                    retrieval         customization     analysis

  Knowledge Updates Instant           Requires          Update prompt only
                                      retraining        

  Hallucinations    Low               Medium            Low
                                                        (context-dependent)

  Best For          Dynamic data      Tone, style,      Large codebases &
                                      skills            documents

  Latency           Medium            Fast              Higher TTFT

  Cost              Moderate          High training     High token cost
                                      cost              
  ---------------------------------------------------------------------------

------------------------------------------------------------------------

## Typical Use Cases

### RAG

-   Customer support
-   Enterprise search
-   Internal knowledge bases
-   Live documentation

### Fine-Tuning

-   JSON formatting
-   Company writing style
-   Domain-specific behavior

### Long-Context Prompting

-   Repository analysis
-   Multi-document review
-   Legal and research documents

------------------------------------------------------------------------

## Hybrid Approaches

### Fine-Tuning + RAG

Fine-tune the model for behavior and use RAG for up-to-date knowledge.

### RAG + Long Context

Retrieve only the relevant documents with RAG, then analyze them
together in a long context window.

------------------------------------------------------------------------

## Python Cost Comparison

``` python
class CostEvaluator:
    def __init__(self, daily_queries):
        self.monthly_queries = daily_queries * 30

    def long_context_cost(self, tokens, price):
        return self.monthly_queries * tokens / 1_000_000 * price

    def rag_cost(self, tokens, price, vector_db_fee):
        api = self.monthly_queries * tokens / 1_000_000 * price
        return api + vector_db_fee
```
