# 4. PDF Parsing for RAG Pipelines

## Why PDF Parsing is Challenging

PDFs are designed for **visual presentation**, not structured data
storage. They preserve text positions instead of logical reading order,
making extraction difficult.

Common issues with basic text extraction:

-   Broken reading order
-   Mixed headers and footers
-   Corrupted multi-column layouts
-   Unstructured tables

------------------------------------------------------------------------

## PDF Parsing Strategies

### 1. Rule-Based Parsing

**Tools:** PyMuPDF (fitz), pdfplumber

-   Uses character positions and bounding boxes
-   Fast for digital PDFs
-   Limited support for scanned or complex layouts

------------------------------------------------------------------------

### 2. Vision-Based Layout Detection

**Tools:** Unstructured, Marker, LayoutParser

-   Converts pages into images
-   Detects titles, paragraphs, tables, images, headers, and footers
-   Ideal for enterprise documents

------------------------------------------------------------------------

### 3. Vision-Language Models (VLMs)

**Tools:** LlamaParse, GPT-4o, Claude 3.5 Sonnet

-   Reads page images directly
-   Produces structured Markdown
-   Best for scanned PDFs, financial reports, and complex tables

------------------------------------------------------------------------

## Tool Comparison

  Tool           Approach          Tables         Speed Best Use
  -------------- ------------ ----------- ------------- -------------------
  PyMuPDF        Rule-based          Poor     Very Fast Simple PDFs
  pdfplumber     Rule-based      Moderate        Medium Structured tables
  Unstructured   Vision AI           Good        Slower Mixed layouts
  LlamaParse     VLM            Excellent   Cloud-based Production RAG
