# 6. Parsing Markdown, Word & Structured Text for RAG

## 1-Liner Definition

Structured document parsing preserves author-defined hierarchy
(headings, lists, tables, and formatting) so that chunks retain semantic
context before being embedded into a vector database.

------------------------------------------------------------------------

## Markdown Parsing

Markdown is one of the best formats for RAG because it already contains
semantic structure.

**Common tools** - MarkdownHeaderTextSplitter - Mistune - markdown-it

The parser tracks headings (`#`, `##`, `###`) and attaches them as
metadata to each chunk.

------------------------------------------------------------------------

## Word (.docx) Parsing

Word documents are ZIP archives containing XML.

**Common tools** - python-docx - Azure AI Document Intelligence -
LlamaParse

These tools identify:

-   Headings
-   Paragraphs
-   Lists
-   Quotes
-   Tables
-   Images

------------------------------------------------------------------------

## Handling Tables

Tables should never be flattened into plain text.

### Common Strategies

1.  Convert to Markdown or HTML tables.
2.  Generate an LLM summary and embed it.
3.  Parent--Child Retrieval:
    -   Embed the summary.
    -   Retrieve the original table when needed.

------------------------------------------------------------------------

## Handling Images

### Multimodal Embeddings

Use models such as:

-   CLIP
-   ImageBind

to embed images into a shared vector space.

### Captioning & OCR

Generate descriptive captions or extract text using OCR, then embed that
text.

------------------------------------------------------------------------

## Data Cleaning Pipeline

``` text
Raw Text
    ↓
Boilerplate Removal
    ↓
Whitespace Normalization
    ↓
Artifact Cleaning
    ↓
Clean Semantic Chunks
    ↓
Embedding Model
```

### Cleaning Steps

-   Remove repeated headers and footers
-   Normalize whitespace
-   Fix Unicode issues
-   Remove Base64 blobs
-   Remove broken HTML/Markdown tags

------------------------------------------------------------------------

## Python Example

``` python
import re

text = re.sub(r"\n{3,}", "\n\n", raw_text)

# remove repeated headers
text = text.replace("CONFIDENTIAL - INTERNAL USE ONLY", "")

# clean markdown artifacts
text = re.sub(r"<[^>]+>", "", text)

print(text)
```
