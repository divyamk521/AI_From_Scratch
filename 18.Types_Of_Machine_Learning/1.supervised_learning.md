# Types of Machine Learning

## A. Supervised Learning

### 1-Liner Definition

Supervised Learning is a type of machine learning where a model learns from examples that already contain the correct answers.

### Short Technical Explanation

In supervised learning, we provide a model with **input data (X)** and its corresponding **correct output (y)**.

The model studies the relationship between the inputs and outputs during training. After learning these patterns, it predicts outputs for new, unseen data.

Think of it like learning with a teacher: the teacher gives you questions along with their correct answers, and you learn how to solve similar questions.

- **Features (X):** The information given to the model.
- **Labels or targets (y):** The correct answers the model learns to predict.
- **Training:** The process of learning patterns from examples.
- **Prediction:** The answer produced for new input data.

### Real-World Scenarios

- **Email Spam Detection:** Learn from emails labeled as spam or not spam.
- **House Price Prediction:** Learn from house sizes, locations, and historical selling prices.
- **Disease Detection:** Learn from medical data with known diagnoses.
- **Sales Forecasting:** Learn from historical sales figures to estimate future sales.

### Code Snippet

```python
# A simple example of learning from labeled data

# Features (X): hours studied
X = [[1], [2], [3], [4], [5]]

# Labels (y): exam scores
y = [20, 35, 50, 65, 80]

from sklearn.linear_model import LinearRegression

# Create the model
model = LinearRegression()

# Train the model using examples and correct answers
model.fit(X, y)

# Predict the score for a student who studies 6 hours
prediction = model.predict([[6]])

print("Predicted score:", prediction[0])
```

**Understand the code:**

- `X` contains the hours studied.
- `y` contains the corresponding exam scores.
- `model.fit(X, y)` teaches the model using the examples.
- `model.predict([[6]])` asks the trained model to predict the score for 6 hours of study.

This example uses a simplified, artificially created dataset to demonstrate the concept. Real data will not always follow such a perfect pattern.

## B. Regression Problems

### 1-Liner Definition

Regression is a type of supervised learning used to predict a **numerical value**, such as a price, temperature, salary, or sales amount.

### Short Technical Explanation

In regression, the model learns how input features are related to a continuous numerical target.

For example, a house's price may depend on its size, location, number of bedrooms, and age.

The model learns from houses whose prices are already known and predicts a price for a new house.

**Remember:** Regression answers questions like *How much? How many? What value?*

Common regression algorithms include:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

### Real-World Scenarios

- **House Price Prediction:** Estimate a house's price based on its features.
- **Salary Prediction:** Estimate salary based on experience, skills, and location.
- **Sales Forecasting:** Estimate how much a store may sell next month.
- **Weather Prediction:** Estimate tomorrow's temperature.
- **Demand Forecasting:** Estimate the number of products customers may buy.

### Code Snippet

```python
from sklearn.linear_model import LinearRegression

# Input feature: house size in square feet
X = [[500], [700], [1000], [1200], [1500]]

# Target: house price in lakhs
y = [20, 28, 40, 48, 60]

# Create the regression model
model = LinearRegression()

# Train using known house sizes and prices
model.fit(X, y)

# Predict the price of a 1,100 sq. ft. house
predicted_price = model.predict([[1100]])

print("Predicted price:", predicted_price[0], "lakhs")
```

**Understand the code:**

- `X` contains house sizes.
- `y` contains known house prices.
- `fit()` helps the model learn the relationship between size and price.
- `predict()` estimates the price of a house it has not seen before.

The data is fictional and assumes a simplified relationship between size and price.

## C. Classification Problems

### 1-Liner Definition

Classification is a type of supervised learning used to predict a **category or class**, such as spam or not spam, positive or negative, or cat or dog.

### Short Technical Explanation

In classification, the model learns patterns from input features and their known category labels.

After training, it predicts which category a new input most likely belongs to.

Unlike regression, which predicts a numerical target, classification predicts a class. Some classifiers also provide probabilities for each class.

**Remember:** Classification answers questions like *Which category? Which type? Yes or no?*

Common classification algorithms include:

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)

Despite its name, Logistic Regression is commonly used for classification.

### Real-World Scenarios

- **Spam Detection:** Classify emails as spam or not spam.
- **Fraud Detection:** Classify transactions as potentially fraudulent or legitimate.
- **Sentiment Analysis:** Classify reviews as positive, negative, or neutral.
- **Image Recognition:** Classify an image as a cat, dog, or bird.
- **Customer Churn Prediction:** Predict whether a customer is likely to leave a service.

### Code Snippet

```python
from sklearn.tree import DecisionTreeClassifier

# Input feature: number of suspicious words in an email
X = [[0], [1], [2], [5], [7], [9]]

# Labels: 0 = Not Spam, 1 = Spam
y = [0, 0, 0, 1, 1, 1]

# Create the classification model
model = DecisionTreeClassifier(random_state=42)

# Train the model
model.fit(X, y)

# Classify a new email containing 6 suspicious words
prediction = model.predict([[6]])

if prediction[0] == 1:
    print("Spam")
else:
    print("Not Spam")
```

**Understand the code:**

- `X` contains the input feature.
- `y` contains the correct categories.
- `0` represents Not Spam, while `1` represents Spam.
- The decision tree learns patterns from the labeled examples.
- `predict()` returns the predicted category.

This is a teaching example with just one artificial feature. A real spam detector would need much richer information, such as email text, links, sender information, and other relevant features.

## D. Labeled Data Concept

### 1-Liner Definition

Labeled data is data where each example has an input and its corresponding correct answer or category.

### Short Technical Explanation

A labeled dataset contains two important parts:

- **Input (X):** The information the model uses to learn.
- **Label (y):** The correct answer associated with that input.

During supervised learning, the model uses these examples to learn patterns that help it make predictions on new data.

For example, consider the following dataset:

| Hours Studied (X) | Exam Score (y) |
|---:|---:|
| 1 | 20 |
| 2 | 35 |
| 3 | 50 |
| 4 | 65 |

Here, the hours studied are the input features, and the exam scores are the labels.

For classification, labels can instead be categories:

| Email Text | Label |
|---|---|
| "You won a free prize!" | Spam |
| "Meeting at 10 AM" | Not Spam |
| "Claim your cash reward!" | Spam |

The model learns from these examples and uses the learned patterns to classify future emails.

**Important:** Labeled data does not always mean data labeled with words. A number can be a label in regression, and a category or class identifier can be a label in classification.

### Real-World Scenarios

- **Machine Learning Datasets:** Images labeled as cats or dogs train an image classifier.
- **Healthcare:** Patient records with confirmed diagnoses can train a disease-classification model.
- **E-commerce:** Historical product features and selling prices can train a price-prediction model.
- **Customer Reviews:** Reviews labeled positive or negative can train a sentiment classifier.
- **Autonomous Driving:** Images annotated with cars, pedestrians, and road signs help train object-detection models.

### Code Snippet

```python
# A tiny labeled dataset for fruit classification

# Input features: weight in grams
X = [[100], [120], [150], [180], [200]]

# Labels: 0 = Apple, 1 = Orange
y = [0, 0, 0, 1, 1]

from sklearn.tree import DecisionTreeClassifier

model = DecisionTreeClassifier(random_state=42)

# Learn from labeled examples
model.fit(X, y)

# Predict the fruit category for a 190-gram fruit
prediction = model.predict([[190]])

if prediction[0] == 0:
    print("Apple")
else:
    print("Orange")
```

**Understand the code:**

- `X` contains the fruit weights.
- `y` provides the correct fruit labels for the training examples.
- `fit()` learns from the input-label pairs.
- `predict()` estimates the category for a new example.

This toy dataset uses weight alone, so it cannot reliably identify real fruit. Actual models generally require more useful features, such as color, shape, and texture.

## E. Understand the Difference

| Concept | What It Predicts or Represents | Example |
|---|---|---|
| Supervised Learning | Learns from inputs with known answers | Learning from past house sales |
| Regression | A numerical value | Predicting a house price of ₹45 lakhs |
| Classification | A category or class | Predicting Spam or Not Spam |
| Labeled Data | Inputs paired with correct answers | House size paired with its actual selling price |

### How These Concepts Connect

**Supervised Learning** uses labeled examples to train a model.

- **Regression:** Predicts a number, such as a house price.
- **Classification:** Predicts a category, such as Spam or Not Spam.
- **Labeled Data:** Supplies the examples and correct answers used to train either type of model.
