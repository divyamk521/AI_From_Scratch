# Machine Learning: Labeled Data, Unsupervised, Semi-Supervised, and Self-Supervised Learning

## A. Labeled Data Concept

### 1-Liner Definition
**Labeled data** is data where each example contains input features and a known target, answer, or category.

### Short Technical Explanation
- **Features (`X`):** information supplied to the model.
- **Labels/targets (`y`):** the known answers associated with those inputs.
- **Training:** learning a relationship from input-target examples.
- **Prediction:** estimating an answer for unseen input.

A label can be numerical (a house price) or categorical (spam/not spam). Numerical targets commonly appear in regression; categorical targets appear in classification.

### Real-World Scenarios
- Photos labelled as cats or dogs for image classification.
- Emails labelled spam/not spam.
- House features paired with actual selling prices.
- Patient records paired with confirmed diagnoses.
- Road images annotated with pedestrians and vehicles.

### Code Snippet
```python
from sklearn.linear_model import LinearRegression

# X: hours studied; y: known exam scores
X = [[1], [2], [3], [4], [5]]
y = [20, 35, 50, 65, 80]

model = LinearRegression()
model.fit(X, y)

prediction = model.predict([[6]])
print("Predicted score:", prediction[0])
```

### Understand the Code
- `X` contains the feature values.
- `y` contains the known target values.
- `fit(X, y)` learns from labelled examples.
- `predict([[6]])` estimates a score for a new input.
- The dataset is artificial and demonstrates the idea, not a real-world guarantee.

## B. Unsupervised Learning

### 1-Liner Definition
**Unsupervised learning** discovers patterns or structure in data without training against known target labels.

### Short Technical Explanation
An unsupervised algorithm receives input data `X` without a target vector `y`. It discovers structure using an objective suited to the task.

Common tasks:
- **Clustering:** group similar examples.
- **Dimensionality reduction:** represent data with fewer dimensions.
- **Association rule learning:** find items that frequently occur together.
- **Anomaly detection:** identify observations that differ from typical patterns.

The resulting patterns need evaluation and interpretation; an algorithm does not automatically know their business meaning.

### Real-World Scenarios
- Customer segmentation based on spending or browsing behaviour.
- Grouping support tickets without manually labelling every ticket.
- Finding products often bought together.
- Visualising high-dimensional data.
- Exploring unusual network or sensor behaviour.

### Code Snippet
```python
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

# Rows are customers: [monthly spending, visits per month]
X = [
    [500, 2], [600, 3], [550, 2],
    [8000, 15], [9000, 17]
]

X_scaled = StandardScaler().fit_transform(X)
model = KMeans(n_clusters=2, random_state=42, n_init=10)
cluster_ids = model.fit_predict(X_scaled)

for customer, cluster_id in zip(X, cluster_ids):
    print(customer, "-> cluster", cluster_id)
```

### Understand the Code
- `X` contains features but no customer-type labels.
- `StandardScaler` puts features on comparable scales.
- `n_clusters=2` asks K-Means to find two groups.
- `fit_predict()` learns the grouping and assigns each example a cluster ID.
- Cluster IDs such as `0` and `1` are arbitrary; they do not inherently mean “good” or “bad.”

## C. Clustering

### 1-Liner Definition
**Clustering** groups data points according to a chosen distance, similarity, or density criterion.

### Short Technical Explanation
- **K-Means:** assigns points to centroids and updates the centroids to reduce within-cluster squared distances.
- **DBSCAN:** identifies dense regions and can mark isolated observations as noise.
- **Hierarchical clustering:** builds nested groups that can be viewed as a tree.
- **Gaussian Mixture Models (GMM):** model data as a mixture of probability distributions and can provide soft membership probabilities.

No method is best for every dataset. Results depend on features, scaling, assumptions, and parameters.

### Real-World Scenarios
- Customer segmentation.
- Grouping text embeddings by topic.
- Image and pixel grouping.
- Exploring manufacturing sensor patterns.
- Discovering structure before training a predictive model.

### Code Snippet
```python
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

# [hours studied, practice problems completed]
X = [
    [1, 2], [1.5, 3], [2, 2],
    [7, 12], [8, 14], [9, 15]
]

X_scaled = StandardScaler().fit_transform(X)
model = KMeans(n_clusters=2, random_state=42, n_init=10)
labels = model.fit_predict(X_scaled)

print("Cluster IDs:", labels)
print("Cluster centres:", model.cluster_centers_)
```

### Understand the Code
1. Features are standardised so one scale does not dominate the distance calculation.
2. K-Means assigns points to their nearest centroid.
3. It recalculates each centroid from its assigned points.
4. Assignment and update repeat until the solution stabilises.

### Concepts to Master
- Euclidean and cosine distance.
- Feature scaling, centroids, and within-cluster variation.
- Choosing the number of clusters.
- Silhouette score and cluster stability.
- K-Means vs. DBSCAN vs. hierarchical clustering.

## D. Dimensionality Reduction

### 1-Liner Definition
**Dimensionality reduction** transforms data with many features into fewer dimensions while trying to preserve useful information or structure.

### Short Technical Explanation
A dataset with hundreds of features can be mapped into a smaller representation. This can simplify visualisation, reduce computational cost, or help downstream modelling.

- **PCA:** projects data onto orthogonal directions that capture as much variance as possible.
- **SVD:** factorises a matrix and can produce lower-rank representations.
- **t-SNE:** mainly visualises local neighbourhoods in two or three dimensions.
- **UMAP:** creates low-dimensional representations based on neighbourhood structure.
- **Autoencoders:** neural networks learn compact latent representations, often by reconstructing the input.

PCA is a good starting point. Standardise features when their units or scales differ. A reduced representation can lose information useful for a specific task.

### Real-World Scenarios
- Visualising high-dimensional text or image embeddings.
- Compressing features before downstream analysis.
- Exploring gene-expression datasets.
- Removing low-variance directions when appropriate.
- Exploring complex datasets during analysis.

### Code Snippet
```python
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

X, _ = load_iris(return_X_y=True)
X_scaled = StandardScaler().fit_transform(X)

pca = PCA(n_components=2)
X_reduced = pca.fit_transform(X_scaled)

print("Original shape:", X.shape)
print("Reduced shape:", X_reduced.shape)
print("Variance retained:", pca.explained_variance_ratio_.sum())
```

### Understand the Code
- The Iris dataset has four features per sample.
- `StandardScaler` standardises those features.
- `PCA(n_components=2)` creates two principal-component coordinates.
- `fit_transform()` learns the PCA directions and transforms the data.
- `explained_variance_ratio_.sum()` reports the variance fraction retained by the two components.

Retained variance does not guarantee that every detail useful for a prediction task is preserved.

### Concepts to Master
- Variance, covariance, and projections.
- Principal components and explained variance.
- Reconstruction error.
- PCA vs. t-SNE vs. UMAP.
- Latent spaces and autoencoders.
- Why a 2D embedding can be misleading.

## E. Association Rule Learning

### 1-Liner Definition
**Association rule learning** discovers items or events that frequently occur together and expresses their relationships as rules.

### Short Technical Explanation
It is commonly used on transaction data, where each transaction contains a set of items. Algorithms such as **Apriori** and **FP-Growth** find frequent itemsets, from which rules are generated.

For a rule `A -> B`:
- **Support:** fraction of all transactions containing both A and B.
- **Confidence:** fraction of transactions containing A that also contain B.
- **Lift:** confidence divided by the overall frequency of B.

Formulas:

- `support(A -> B) = support(A and B)`
- `confidence(A -> B) = support(A and B) / support(A)`
- `lift(A -> B) = confidence(A -> B) / support(B)`

Lift greater than 1 indicates that B occurs with A more often than its overall baseline rate. It does not prove causation.

### Real-World Scenarios
- Market-basket analysis.
- Complementary-product recommendations.
- Retail inventory planning.
- Finding items commonly consumed in the same session.
- Exploring co-occurrence patterns for further research.

### Code Snippet
```python
# Install if needed: pip install mlxtend pandas
import pandas as pd
from mlxtend.preprocessing import TransactionEncoder
from mlxtend.frequent_patterns import apriori, association_rules

transactions = [
    ["bread", "milk"],
    ["bread", "butter"],
    ["bread", "milk", "butter"],
    ["milk", "butter"],
    ["bread", "milk"]
]

encoder = TransactionEncoder()
encoded = encoder.fit(transactions).transform(transactions)
basket = pd.DataFrame(encoded, columns=encoder.columns_)

itemsets = apriori(basket, min_support=0.4, use_colnames=True)
rules = association_rules(
    itemsets, metric="confidence", min_threshold=0.6
)

print(itemsets)
print(rules[[
    "antecedents", "consequents", "support", "confidence", "lift"
]])
```

### Understand the Code
- `TransactionEncoder` converts transactions into a Boolean table.
- `apriori()` finds itemsets meeting the support threshold.
- `association_rules()` generates rules and calculates their metrics.
- `antecedents` are the left side of a rule; `consequents` are the right side.
- Thresholds affect which rules are returned.

### Concepts to Master
- Transaction encoding and frequent itemsets.
- Apriori and its pruning principle.
- FP-Growth.
- Support, confidence, and lift.
- Threshold selection and misleading rules.

## F. Semi-Supervised Learning

### 1-Liner Definition
**Semi-supervised learning** trains a model using a small labelled dataset together with a larger unlabelled dataset.

### Short Technical Explanation
Labelling data can be expensive or require experts. Semi-supervised methods try to use unlabelled examples to improve learning beyond what the labelled subset alone provides.

Common techniques:
- **Self-training / pseudo-labeling:** predict labels for unlabelled examples and add selected high-confidence predictions to training.
- **Consistency regularization:** encourage similar predictions for slightly perturbed versions of the same input.
- **Graph-based methods:** use relationships among similar samples to propagate label information.
- **Semi-supervised deep learning:** combine supervised loss with objectives that exploit unlabelled data.

Incorrect pseudo-labels can reinforce mistakes. Keep a separate labelled validation/test set and never use test labels during training.

### Real-World Scenarios
- Medical imaging with a small expert-labelled set.
- Content moderation with a small reviewed set of posts.
- Speech recognition with limited transcripts and more untranscribed audio.
- Manufacturing with a few inspected defects and many uninspected images.
- Document classification with only a subset of tickets labelled.

### Code Snippet
```python
import numpy as np
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.semi_supervised import SelfTrainingClassifier
from sklearn.metrics import accuracy_score

X, y = load_digits(return_X_y=True)

# Hold out a separate test set.
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)

# Pretend only 10% of training labels are available.
rng = np.random.default_rng(42)
labelled_mask = rng.random(len(y_train)) < 0.10
y_partial = np.full(y_train.shape, -1)
y_partial[labelled_mask] = y_train[labelled_mask]

base_model = make_pipeline(
    StandardScaler(),
    LogisticRegression(max_iter=2000)
)
model = SelfTrainingClassifier(base_model, threshold=0.8)
model.fit(X_train, y_partial)

predictions = model.predict(X_test)
print("Test accuracy:", accuracy_score(y_test, predictions))
print("Initially labelled:", labelled_mask.sum())
```

### Understand the Code
- The digits dataset contains images represented as numerical features.
- Only about 10% of training examples retain their labels.
- `-1` indicates an unlabelled training example to scikit-learn.
- The classifier can add confident predictions as pseudo-labels.
- The untouched test set measures generalisation.

This example demonstrates the workflow; self-training is not guaranteed to outperform a labelled-only baseline.

### Concepts to Master
- Labelled/unlabelled splits.
- Pseudo-labels and confidence thresholds.
- Consistency regularization and label propagation.
- Confirmation bias and class imbalance.
- Baselines, evaluation, and data leakage prevention.

## G. Self-Supervised Learning

### 1-Liner Definition
**Self-supervised learning** automatically creates training targets from unlabelled data so a model can learn useful features or representations without manual labels.

### Short Technical Explanation
The training procedure creates a prediction task from the data itself.

Examples:
- **Causal language modelling:** predict the next token from previous tokens.
- **Masked language modelling:** predict tokens hidden from the input.
- **Contrastive learning:** bring representations of related views together and separate unrelated examples.
- **Masked image modelling:** predict information about hidden image patches.
- **Representation learning:** learn embeddings reusable in downstream tasks.

Typical workflow:
1. Collect unlabelled data.
2. Construct a self-supervised objective.
3. Train an encoder or model.
4. Reuse the representation for a downstream task, optionally with fine-tuning.

Self-supervised learning is a training strategy, not one specific algorithm. It is widely used to pretrain language, vision, and audio models.

### Real-World Scenarios
- Pretraining language models on text.
- Learning visual features from unlabelled images.
- Semantic search using document embeddings.
- Learning speech representations without transcripts for every recording.
- Pretraining broadly and adapting to a specific task.

### Code Snippet
This toy example automatically derives the target word from each sentence. It illustrates generated targets, not a production language model.

```python
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.linear_model import LogisticRegression

sentences = [
    "cats drink milk",
    "dogs drink water",
    "birds eat seeds",
    "cats eat fish",
    "dogs eat meat"
]

prefixes, next_words = [], []
for sentence in sentences:
    words = sentence.split()
    prefixes.append(" ".join(words[:2]))
    next_words.append(words[2])

vectorizer = CountVectorizer()
X = vectorizer.fit_transform(prefixes)

model = LogisticRegression()
model.fit(X, next_words)

test_prefix = ["cats eat"]
prediction = model.predict(vectorizer.transform(test_prefix))
print("Predicted next word:", prediction[0])
```

### Understand the Code
- Each sentence supplies an input prefix and a target word.
- The target is generated from the sentence; a person did not manually annotate it.
- `CountVectorizer` converts prefixes into numerical features.
- The classifier learns a simple prefix-to-word mapping.

This tiny example only illustrates the idea. Real self-supervised models use much larger datasets, richer architectures, and carefully designed objectives.

### Concepts to Master
- Pretext and training objectives.
- Causal and masked language modelling.
- Contrastive learning and positive/negative pairs.
- Embeddings and latent representations.
- Pretraining, fine-tuning, and transfer learning.
- Downstream evaluation.

## H. Understand the Differences

| Concept | Label situation | Main purpose | Example |
|---|---|---|---|
| Labeled data | Inputs paired with known targets | Supplies examples for supervised training | House sizes paired with prices |
| Unsupervised learning | No target labels used | Discover patterns | Group customers |
| Clustering | No target labels required | Group similar examples | Customer segmentation |
| Dimensionality reduction | Labels not required for common methods such as PCA | Compress or visualise data | Reduce 100 features to 2 components |
| Association rule learning | Transaction data, without a target label | Discover co-occurrences | Products bought together |
| Semi-supervised learning | Small labelled set plus unlabelled data | Improve a target task with limited labels | Classify partly labelled images |
| Self-supervised learning | Targets generated from data | Learn representations or a prediction task | Predict masked or next tokens |

### How They Can Work Together
For a document-search system:
1. A pretrained/self-supervised encoder converts documents into embeddings.
2. Dimensionality reduction can help visualise embeddings.
3. Clustering can reveal groups of related documents.
4. Semi-supervised learning can use a small labelled subset to train a classifier.
5. Association rules can find co-occurrences if the data is represented as transactions or item sets.

These methods are complementary; one project can use several.
